# WEEKLYREPORT — Local Weekly Commodity Report Pipeline

A simple, local Python pipeline for generating professional weekly commodity
market reports. Historical reports are used as style and narrative references
only — they are never copied into the new report.

---

## Project Purpose

This pipeline automates the generation of HigbyBarrett weekly commodity market
reports by:

1. Converting historical PDF/DOCX reports into clean markdown text
2. Classifying them by report type (post_wasde, pre_wasde, weekly)
3. Selecting the most relevant historical reports as style references
4. Combining current weekly data, a style guide, and writing instructions into a prompt
5. Passing that prompt to an LLM to generate a new report draft

Everything runs locally. No cloud infrastructure required.

## Folder Structure

```
WEEKLYREPORT/
├── reports_raw/        # Drop your original PDF and DOCX files here
├── reports_clean/      # Converted markdown (auto-generated by convert_reports.py)
├── reports_final/      # Cleaned markdown ready for use as references
├── weekly_data/        # Weekly market data: one subfolder per report date
│   └── 2026-03-12/     # Example: data pack for March 12 report
│       ├── prices.md
│       ├── exports.md
│       ├── wasde.md    # post_wasde mode only
│       ├── weather.md
│       └── notes.txt
├── prompts/            # Style guide, writing instructions, selected references, built prompts
├── scripts/            # All pipeline scripts
├── output/             # Generated prompts and report drafts (auto-generated)
├── logs/               # Log files (auto-generated)
├── README.md           # This file
├── CLAUDE.md           # Persistent instructions for Claude Code
└── requirements.txt    # Python dependencies
```

## First-Time Setup

```bash
pip install -r requirements.txt
```

Historical reports only need to be processed once:

```bash
# Convert PDFs to markdown
python scripts/convert_reports.py

# Clean the markdown (removes headers, footers, page numbers)
python scripts/clean_reports.py

# Build the style corpus (combines all cleaned reports into one reference file)
python scripts/build_style_corpus.py
```

## Weekly Workflow

### Step 1 — Add your weekly data

Create a subfolder in `weekly_data/` named by today's date and add your data files:

```
weekly_data/
└── 2026-03-12/
    ├── prices.md     ← CME futures, spreads, % of full carry
    ├── exports.md    ← USDA inspections and sales
    ├── wasde.md      ← WASDE numbers (post_wasde only)
    ├── weather.md    ← crop progress and South American weather
    └── notes.txt     ← analyst observations (optional)
```

See `weekly_data/README.md` for the expected content of each file.

### Step 2 — Generate the prompt

Run one command depending on your report type:

**Post-WASDE** (WASDE was released this week):
```bash
python scripts/generate_report.py --mode post_wasde --date 2026-03-12
```

**Pre-WASDE** (WASDE is due next week):
```bash
python scripts/generate_report.py --mode pre_wasde --date 2026-03-12
```

**Weekly** (no major USDA report this week):
```bash
python scripts/generate_report.py --mode weekly --date 2026-03-12
```

### Step 3 — Use the prompt

The script saves the assembled prompt to:
```
output/post_wasde_prompt.txt   (or pre_wasde_prompt.txt / weekly_prompt.txt)
```

**Option A — Paste it manually** into Claude, ChatGPT, or any LLM.

**Option B — Connect an LLM** by implementing `call_llm()` in
`scripts/generate_report.py`. The generated report will be saved automatically
to `output/<date>_<mode>_report.md`.

---

## Report Modes Explained

| Mode | When to use | Primary focus |
|---|---|---|
| `post_wasde` | The week WASDE was released | WASDE balance sheet changes, market reaction, how cash adjusted |
| `pre_wasde` | The week before WASDE | Market setup, trade expectations, WASDE risk scenarios |
| `weekly` | All other weeks | Current price drivers, basis, exports, positioning |

The pipeline automatically selects historical reference reports that match
your chosen mode, so the LLM sees examples of the right kind of report.

---

## What Each Script Does

| Script | Purpose |
|---|---|
| `convert_reports.py` | Converts PDF/DOCX from `reports_raw/` to markdown in `reports_clean/` |
| `clean_reports.py` | Removes headers, footers, page numbers; saves to `reports_final/` |
| `build_style_corpus.py` | Combines all cleaned reports into `prompts/style_corpus.md` |
| `select_reports.py` | Classifies reports by type and selects the best references for a mode |
| `build_prompt.py` | Assembles style guide + instructions + references + weekly data into one prompt |
| `generate_report.py` | Orchestrates the full pipeline; saves prompt to `output/` |

## Running Steps Individually

You can also run each step separately for more control:

```bash
# 1. Select reference reports for your mode
python scripts/select_reports.py --mode post_wasde --n 3

# 2. Build the prompt file
python scripts/build_prompt.py --mode post_wasde --date 2026-03-12 --data-dir weekly_data/2026-03-12

# 3. Inspect the prompt before using it
cat prompts/prompt_2026-03-12_post_wasde.txt

# 4. Generate (runs steps 1 and 2 automatically, then calls LLM if connected)
python scripts/generate_report.py --mode post_wasde --date 2026-03-12
```

---

## Connecting an LLM

Open `scripts/generate_report.py` and replace the body of `call_llm()` with
one of the examples in the `LLM INTEGRATION` comment block. Three options are
provided: Ollama (local), Anthropic Claude API, and OpenAI API.

Once connected, the generated report is saved to:
```
output/<date>_<mode>_report.md
```
